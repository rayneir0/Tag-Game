# Tag Game
## Background
This is a pokemon themed game of tag, where you can play tag with an AI, if the player is tagged when the timer runs out, the point is given to the AI.

## How To Play
- To start the game press start on the main menu.
- Once you are in a timer will count you down and you can begin firing at the opponent.
- If you are not caught by the end of the 3 minutes you gain a point.
- These points accumulate in the leaderboard section.
- To get to the leaderboard section you can either wait for the game to end, or press ESC and the main menu button.
- Pressing the main menu buttons on the pause menu and game over menu will bring you back to the start screen.
- The exit button on the start screen will close the game
- The leaderboard button on the screen will bring you to a screen with a total tally of points for each player.

## Controls
- Right mouse button to shoot.
- ESC to get to the pause menu.
- WASD to move forward, sideways and backwards.
- Mouse to look around
